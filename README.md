# Landing page Raiz

Landing page estática e responsiva para apresentação do produto Raiz.

## Prévia local

Na pasta do projeto, execute:

```powershell
python -m http.server 4173
```

Depois, acesse `http://localhost:4173`.

O CTA final usa `ola@raiz.app` como endereço provisório; substitua-o pelo canal oficial antes da publicação.
